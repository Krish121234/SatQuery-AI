🔍 Mock Pipeline Architecture

The pipeline simulates the complete workflow with three main components:

1. Sai's Grounding Pipeline

Analyzes images and splits them into a 3x3 grid (9 tiles). Each tile is classified into one of 5 land cover classes: Agriculture, Water, Vegetation, Built-up, or Barren. Each classification includes a confidence score (0.75–0.99).

2. Sid's Gemini Integration

Takes the grounding data + user question and generates a natural English answer. The simulator intelligently responds based on keywords in the question (agriculture, water, vegetation, built-up, change, etc.) and incorporates the grounding data into coherent answers.

3. Change Detection Logic

Compares before/after grounding results, identifies which tiles changed classification, calculates confidence changes, and generates a summary. Example: "Tile 4 changed from Farm to Water" with detailed tile-by-tile breakdown.

🚀 Quick Start

  1. Navigate to the backend folder
  2. Install dependencies: pip install -r requirements.txt
  3. Run the server: python -m uvicorn main:app --reload
  4. Open http://localhost:8000/docs for interactive API documentation

📍 Running the Backend

pip install -r requirements.txt
python -m uvicorn main:app --reload
